# Per-video charts

Generated by `scripts/analyze.py`, three charts for each of the 728 videos:

- [`file-size-comparison/`](file-size-comparison/README.md): file size of the video, of an Arrow IPC file (`.arrow`) of the same batches and of the Parquet files the server stored.
- [`server-time/`](server-time/README.md): upload time, server receive time and the server's Parquet encode and write time, with [`all-videos.png`](server-time/all-videos.png) for all videos.
- [`client-time/`](client-time/README.md): client steps before the upload (read the file, split it into record batches, encode Flight messages), with [`all-videos.png`](client-time/all-videos.png) for all videos.
