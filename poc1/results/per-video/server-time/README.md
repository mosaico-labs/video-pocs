# Server time per video

## What to improve first

- **Parquet encode: 4.69 s, 38% of the server receive time.** Each batch is encoded before the next message is read, as in mosaicod's `do_put`. Encoding a batch while the next one arrives would overlap the two.
- Then: Receiving and checking messages 3.97 s (32%), Parquet write 3.80 s (30%).

The server receive time is 98% of the upload time, so speeding up these steps speeds up the upload.
