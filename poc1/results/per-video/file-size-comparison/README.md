## What to improve first

- **Parquet vs video: +35.34 MiB (+0.124%), about 1.3 KiB per Parquet file over 28,894 files.** The overhead is per file (footer, schema, bloom filter and the `timestamp_ns`, `chunk_index` and `offset` columns), so fewer, bigger files shrink it: raise `--chunks-per-batch`, up to the 50 MiB message limit. It would also mean fewer files and statistics rows for mosaicod.
- For reference, `.arrow`, one file per video, is +24.28 MiB (+0.085%). Both are well under 1% of the video, so size matters less than time: see [`../server-time/`](../server-time/README.md) and [`../client-time/`](../client-time/README.md).
